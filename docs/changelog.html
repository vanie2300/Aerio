Changelog

Version history of Tabloid Browser.

v1.0.0

Initial release

Browsing

  • Tab management with Ctrl+T, Ctrl+W, Ctrl+Tab
  • Address bar with inline search suggestions
  • Quick links on start page
  • History tracking (500 items)
  • Download manager

Bookmarks

  • Bookmark any page
  • Bookmark manager at tabloid://bookmarks
  • Drag and drop reordering
  • Nested folder support

Find

  • Find in page with Ctrl+F
  • Highlight all matches
  • Navigate between matches

Settings

  • Appearance (theme, accent color, background)
  • Search engine selection (DuckDuckGo, Startpage, Brave, SearXNG)
  • Tab sleep timer
  • Tracker blocking and ad blocking
  • Per-site permissions
  • Clear data on exit

Developer Tools

  • DevTools toggle (F12)
  • Dark page inversion

v1.1.0

AI features and privacy

AI Sidebar

  • Integrated AI chat sidebar (Ctrl+Shift+A)
  • Support for OpenAI-compatible APIs (Ollama, OpenAI, Groq, OpenRouter)
  • Agent tool calling with 8 tools
  • Web search integration (DuckDuckGo Lite, SearXNG, custom)
  • Page context for page-aware AI responses
  • Markdown rendering in chat
  • Per-tab chat history
  • Model auto-discovery

Privacy

  • Per-site permission requests
  • Geolocation, media, clipboard, notification permissions
  • One-click deny/allow

Tab Management

  • Tab hibernation (configurable timer)
  • Tab hover preview

Security

  • API key encryption with Windows DPAPI
  • Automatic migration of legacy plaintext keys

UI

  • Start page particle animation
  • Toolbar customization

v1.2.0

Refinements and fixes

  • Settings JSON persistence
  • Session restore
  • Bookmark drag-and-drop reorder
  • UI tweaks and polish
  • Various bug fixes

v1.3.0

Extensions and media

  • uBlock Origin extension integration
  • Custom search engine support
  • Media detection (audio/video players)
  • Media controls (play/pause, volume, seek)

v1.4.0

Quality, streaming, and onboarding

Structured Logging

  • Replaced Debug.WriteLine with Serilog across 13+ files
  • Daily rolling log files with automatic rotation
  • 100+ debug and info calls added

Security

  • AI prompt injection protection with 29 pattern rules
  • Page content sanitized before AI injection
  • Tool-call confirmation for sensitive operations

AI Streaming

  • Real-time AI response streaming via SSE
  • Streaming bubble with live typing indicator
  • Tool call delta accumulation by index

Versioning & Onboarding

  • Version-tracked changelog popup on first launch after update
  • Complete v1.0.0–v1.4.0 changelog

Search

  • Bookmark search by title or URL
  • History search by title or URL

AI Management UI

  • Per-tool enable/disable toggles in settings
  • Model and endpoint configuration page

Quality

  • 55 unit tests across 4 test files
  • Exception handling audit with logging for empty catch blocks
  • Resource disposal fixes (_rateSemaphore, _searchService)
  • Popup overlap prevention across changelog, AI setup, and permissions popups

CI/CD

  • GitHub Actions workflow for build + test
  • Test results artifact upload (TRX format)
