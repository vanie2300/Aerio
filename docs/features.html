Features

Everything Aerio can do.

Browsing

FeatureDescription
Tabbed browsingCreate, close, reorder, and drag-detach tabs into new windows
Address bar suggestionsFind matching bookmarks and recent history by title or URL; use the arrow keys to select, Enter to open, or Escape to dismiss
Split paneView two tabs side-by-side in a single window
Tab hibernationBackground tabs are suspended after a configurable timeout to free RAM
Session restoreReopens your tabs when the browser restarts
Private browsingIsolated temporary profile that's deleted on close
Reader modeClean article view using Mozilla Readability.js
Find in pageText search with a draggable popup (Ctrl+F)
Zoom25% to 500% zoom with controls in the toolbar
Full screenImmersive full-screen mode (F11)
PrintPrint any page (Ctrl+P)
Force dark pagesCSS invert filter for websites without dark mode
Audio detectionShows which tabs are playing audio with per-tab mute

Start Page

FeatureDescription
Animated particlesSubtle animated background with connection lines
Quick searchProminent centered search box for searching the web or opening an address directly from the start page
Quick linksModern quick-access cards for DuckDuckGo, Startpage, GitHub, and Hacker News
Custom backgroundUse your own image or the default gradient
Background opacityAdjustable brightness for custom backgrounds

Privacy & Security

FeatureDescription
Tracker blockingDomain-based blocking with customizable blocklist and allowlist
Ad blockingEasyList-style filter rules, auto-refreshed every 24 hours
uBlock OriginAuto-download and install the uBlock Origin extension
HTTPS upgradeAutomatically upgrades HTTP to HTTPS for non-local sites
Site permissionsPer-site rules for camera, mic, location, notifications, clipboard, and more
Saved site cookiesReview the domains with cookies in the browser profile; this is an estimate of sign-ins, since cookies can also store preferences and other data
Clear on exitOptional wipe of history, downloads, and session data on close
Download warningsConfirmation dialog for dangerous file types (.exe, .msi, .bat, etc.)

Bookmarks & History

FeatureDescription
BookmarksSave, edit, delete bookmarks with title, URL, and creation date
Import/ExportJSON-based bookmark import and export
HistoryBrowsing history with 500-item limit and deduplication
DownloadsDownload history with 100-item limit

Customization

FeatureDescription

Accent colorsBlue, Purple, Gray, Green, White

Keyboard shortcutsRemappable shortcuts for common actions
