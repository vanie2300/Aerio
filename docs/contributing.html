Contributing

How to set up, develop, and submit changes.

Prerequisites

ToolVersion
.NET SDK8.0 or newer
Windows10 (19041+) or 11
Microsoft Edge WebView2 RuntimeRequired to run from source; the release setup installer bundles it

Setup

git clone https://github.com/vanie2300/Aerio.git
cd Aerio
dotnet restore
dotnet build

Project Structure

  • UI/ — All XAML, controls, styles, assets
  • Processes/ — Business logic, models, services
  • docs/ — GitHub Pages documentation site

See Architecture for the full structure.

Code Style

  • PascalCase for properties, methods, and types
  • _camelCase for private fields
  • async/await for all I/O and WebView2 calls
  • WPF data binding where possible, code-behind for WebView2 integration
  • Partial classes to organize MainWindow (by concern)

Testing

  • Run the xUnit suite with dotnet test TabloidBrowser.Tests\TabloidBrowser.Tests.csproj
  • Test UI changes manually in Aerio on Windows, including light and dark themes where relevant
  • Use a separate Windows profile or back up user data before testing clean-profile behavior
  • Key scenarios: new install, upgrade from older version, settings persistence

Pull Request Process

  1. Fork and create a feature branch
  2. Run the test suite and build the application
  3. Test on Windows 10 or 11
  4. Update docs if adding features or changing settings
  5. Open PR with description of changes

Known Issues

  • The portable ZIP does not bundle WebView2 Runtime; the setup installer includes Microsoft's offline Evergreen Runtime installer
  • Some features may not work on older Windows builds
  • AI features support local Ollama without credentials, Ollama Cloud, and OpenAI-compatible hosted or local APIs
