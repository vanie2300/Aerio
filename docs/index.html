Tabloid Browser

A personal Windows browser built with C#, WPF, and WebView2.

Requirements

  • Windows 10 (19041+) or Windows 11
  • .NET 8 SDK
  • Microsoft Edge WebView2 Runtime

Quick Start

Double-click Run-TabloidBrowser.cmd or run:

dotnet restore
dotnet run

Data Location

%LOCALAPPDATA%\TabloidBrowser\Data

Settings, bookmarks, history, and session data are stored here as JSON files.
