Aerio

A personal Windows browser built with C#, WPF, and WebView2.

Running a release

  • Windows 10 (19041+) or Windows 11
  • Microsoft Edge WebView2 Runtime (installed by the setup installer)

The setup installer bundles the .NET runtime and the offline Microsoft Edge WebView2 Runtime installer, so it can install both prerequisites. The portable ZIP includes the .NET runtime but requires WebView2 Runtime to be installed separately.

Build from source

Building from source requires the .NET 8 SDK and Microsoft Edge WebView2 Runtime. From the repository directory, run:

dotnet restore
dotnet run

The repository also includes the legacy-named Run-TabloidBrowser.cmd development launcher; it builds and starts the Aerio application.

Windows Releases

Every push to main runs tests, builds Aerio, increments the patch version from the latest vMAJOR.MINOR.PATCH tag, and automatically publishes a GitHub Release with the setup installer and portable ZIP. For example, after v1.4.0, the next main push publishes v1.4.1. Pushes to dev and pull requests targeting main build Actions artifacts without publishing releases.

When a version tag is pushed, GitHub Actions creates a release with Aerio-Setup-win-x64.exe and Aerio-win-x64.zip. The setup executable installs Aerio and the bundled WebView2 Runtime (administrator permission is required). The portable ZIP requires WebView2 Runtime to already be installed.

To check for a newer release from within Aerio, use Settings → Advanced → Updates. The check opens the GitHub release page when an update is available; installation is manual.

Data Location

%LOCALAPPDATA%\TabloidBrowser\Data

Settings, bookmarks, history, downloads, and session data are stored here as JSON files. The legacy folder name is retained for compatibility.
