AI Features

Integrated AI chat sidebar with tool calling and web search.

Setup

  1. Open Settings (or navigate to the legacy-compatible tabloid://settings page)
  2. Open the AI assistant settings section and enable the assistant
  3. Choose a provider preset or OpenAI-compatible (custom)
  4. Set the API endpoint. Local Ollama defaults to http://localhost:11434
  5. Enter an API key if the service requires one; local servers commonly do not
  6. Use Test connection to discover models, then select or enter a model name

Press Ctrl+Shift+A or click the AI icon in the toolbar to open the sidebar.

Custom endpoints support compatible services such as LM Studio, llama.cpp, vLLM, OpenRouter, and other OpenAI-compatible gateways. Set the endpoint base URL (or a full /v1/chat/completions URL). Model discovery uses the native Ollama model-list API or the OpenAI-compatible /models API. Services that only expose Anthropic- or Gemini-native APIs are not directly compatible unless they provide an OpenAI-compatible endpoint.

Agent Tools

The AI can use the enabled tools below. The default maximum is 10 tool-calling iterations per message and can be changed in the AI agent settings.

ToolParametersDescription
searchquery (string)Search the web using the browser's selected search engine where supported; unavailable engines fall back to DuckDuckGo, then Bing if needed
search_and_readquery (string), result_index (int, default 0)Search, navigate to a result, and read its content
read_pageoffset, limit (optional integers)Read the current page text, headings, and links
navigateurl (string)Navigate an AI-owned tab to a URL and read it
open_taburl (string), title (optional string)Open a URL in a background tab managed by the AI
clickselector (string)Click an element in the focused page
fillselector, value (strings)Fill a page input field
list_elementsNoneList interactive elements on the focused page
scrolldirection (string), amount (optional integer)Scroll the focused page
close_tabtitle or url (optional)Close an AI-owned tab

AI Web Search

BackendAPI KeyDescription
DuckDuckGoNot requiredDefault search backend; the browser's DuckDuckGo search selection maps here
SearXNGNot requiredUsed when the browser search selection maps to SearXNG
Bing fallbackNot requiredUsed if the selected backend returns no results

AI search uses the browser's selected search engine when supported. Other engines fall back to DuckDuckGo. Requests are rate limited to one per second.

Page Context

When the Include page context toggle is enabled, the current page's text content is included in the AI prompt wrapped in <page_content> tags. This lets the AI answer questions about the page you're viewing.

Security

  • API keys are encrypted with Windows DPAPI on disk
  • Keys are only readable by the same Windows user account
  • Legacy plaintext keys are auto-migrated to encrypted format
