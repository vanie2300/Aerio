AI Features

Integrated AI chat sidebar with tool calling and web search.

Setup

  1. Open Settings (menu gear or tabloid://settings)
  2. Go to the AI tab
  3. Toggle Enable AI
  4. Select a Provider (or use Custom for any OpenAI-compatible API)
  5. Enter your API key if required
  6. Select a Model (auto-discovered from the endpoint)

Press Ctrl+Shift+A or click the AI icon in the toolbar to open the sidebar.

Agent Tools

The AI can use tools to search the web, read pages, and navigate. The agent loop runs up to 10 iterations per message.

ToolParametersDescription
web_searchquery (string)Search the web via DuckDuckGo Lite or SearXNG
search_and_readquery (string), result_index (int, default 0)Search, navigate to a result, and read its content
search_followupquery (string)Get related search suggestions
get_page_content(none)Read the current page's text content (max 8000 chars)
get_page_metadataurl (string, optional)Get page title, description, headings
extract_page_linkssource (string, optional)Extract all hyperlinks from a page
navigate_tourl (string)Navigate the current tab to a URL and read it
open_taburl (string), title (string)Open a URL in a new background tab

Web Search Backends

BackendAPI KeyDescription
DuckDuckGo LiteNot requiredDefault. Scrapes lite.duckduckgo.com
SearXNGNot requiredSelf-hosted or public instance. Set endpoint URL.
CustomVariesGeneric JSON API. Expects results[].title/url/content.

Rate limited to 1 request per second.

Page Context

When the Include page context toggle is enabled, the current page's text content is included in the AI prompt wrapped in <page_content> tags. This lets the AI answer questions about the page you're viewing.

CancellationSend a new message to cancel the current request

Security

  • API keys are encrypted with Windows DPAPI on disk
  • Keys are only readable by the same Windows user account
  • Legacy plaintext keys are auto-migrated to encrypted format
