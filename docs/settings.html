Settings Reference

All settings stored in %LOCALAPPDATA%\TabloidBrowser\Data\settings.json.

Appearance

SettingTypeDefaultDescription
Themestring"Dark"Dark or Light chrome theme
Accentstring"Purple"Accent color: Blue, Purple, Gray, Green, White
Backgroundstring"Default"Start page background: "Default" or image file path
BackgroundOpacitydouble1.0Background image opacity (0.0 - 1.0)
ShowQuickLinksbooltrueShow quick links on start page

Search Engine

SettingTypeDefaultDescription
SearchEnginestring"DuckDuckGo"Default search engine for address bar
CustomEngineslist[]User-defined search engines (name, URL template, optional unique keyword)
SearchKeywordsmapYouTube: "yt", Wikipedia: "wiki"Built-in search keywords; edit them in Settings or leave blank to disable

Built-in engines: DuckDuckGo, Startpage, Brave, SearXNG, and Google. Set YouTube and Wikipedia keywords in Settings → Search engine; defaults are yt and wiki. Leave either blank to disable it. Set an optional, unique keyword when adding a custom engine to search it the same way (for example, vid cats).

Tabs

SettingTypeDefaultDescription
TabSleepMinutesint2Minutes before tab hibernation (1 - 60)

Data

Advanced

AI

See AI Features for provider setup details.

File Format

Settings are stored as a single JSON object. Example:

{
  "Theme": "Dark",
  "Accent": "Purple",
  "SearchEngine": "DuckDuckGo",
  "TabSleepMinutes": 2,
  "BlockTrackers": true,
  "EnableAdBlock": true,
  "AiEnabled": false,
  "AiProvider": "Ollama",
  "AiEndpoint": "http://localhost:11434/v1"
}
