Data Flow

WebView2 tab event
    → MainWindow.WebView2.cs (event handler)
    → MainWindow.Tabs.cs (tab state update)
    → BrowserDataStore.cs (persistence)
    → Settings/History/Bookmarks JSON files

AI Architecture

User input → AiSend_Click
    → AgentLoopAsync (max 10 iterations)
        → AiService.CompleteWithToolsAsync (API call)
        → If tool_calls: AiToolExecutor.ExecuteToolAsync
            → WebSearchService / GetPageContent / NavigateToUrl
        → Add tool results to messages
        → Loop back to API call
    → Display final response in sidebar

Thread Safety

  • ReaderWriterLockSlim protects all data store operations
  • SemaphoreSlim for web search rate limiting
  • Dispatcher.Invoke for UI thread marshaling
  • _tabOperationLock serializes tab mutations

Data Storage
